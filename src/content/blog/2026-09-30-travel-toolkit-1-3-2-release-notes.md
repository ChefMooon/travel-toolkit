Travel Toolkit 1.3.2 brings a visual refresh to the tool cards and navigation,
along with a small fix to make navigation tooltips more predictable.

## A refreshed interface

The tool cards have been polished and the navigation icon refreshed, giving
the interface a cleaner, more consistent appearance.

## More predictable tooltips

Navigation tooltips no longer reappear after you've closed them, so the
interface stays out of your way as you move around.
